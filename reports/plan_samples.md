## P01 V2: Data Analyst (Fresher (0-1 yr))
Learn: ['Tableau']
Problems: none

WEEK 1 (days 1-7): Tableau basics and data connection
- What to learn: Learn the Tableau interface. Connect Tableau to Excel and SQL data. Understand dimensions and measures.
- Daily practice: Spend 1 hour watching and trying basic layout steps. Spend 1 hour building simple bar and line charts.
- Mini project: Connect a sample sales sheet to Tableau and make three basic charts.
- How you know you are ready: You can link data sources and build standard charts without help.

WEEK 2 (days 8-14): Tableau calculations and filters
- What to learn: Learn calculated fields, parameters, filters, and groups to shape your data.
- Daily practice: Practice writing basic math and text formulas inside Tableau for 1 hour. Make interactive filters for 1 hour.
- Mini project: Build a profit calculation field and add regional filters to your charts.
- How you know you are ready: You can use formulas and filters to change what data shows on screen.

WEEK 3 (days 15-21): Tableau dashboards and storytelling
- What to learn: Learn dashboard design rules, layout containers, dashboard actions, and how to tell a clear story with data.
- Daily practice: Spend 1 hour arranging charts nicely on a dashboard. Spend 1 hour testing click actions between charts.
- Mini project: Build a two-page dashboard that shows sales trends and top products clearly.
- How you know you are ready: You can make a clean dashboard that other people can easily read and use.

WEEK 4 (days 22-30): finish the last skill, then build one small project that uses ALL the skills together and add it to the resume.
- What to learn: Review advanced Tableau sharing tips and polish your final design choices.
- Daily practice: Spend 2 hours each day building one big project that uses Python, SQL, Excel, Power BI, Pandas, Statistics, and Tableau.
- Mini project: Clean data with Python and Pandas, store it using SQL, analyze stats in Excel, check insights in Power BI, and build the final public dashboard in Tableau.
- How you know you are ready: Your capstone project is complete, works well, and is ready to show on your resume.

## P01 V1: Data Analyst (Fresher (0-1 yr))
Learn: ['Tableau']
Problems: ['week 1 missing', 'week 2 missing', 'week 3 missing', 'week 4 missing']

Here is a comprehensive, hands-on 30-day learning plan designed to take a student from absolute beginner to a confident Tableau user capable of building professional dashboards. 

This plan requires **1 to 2 hours of study and practice per day**. 

### **Phase 1: Foundations & Data Connection (Days 1–5)**
*Goal: Understand the Tableau interface, connect to various data sources, and grasp basic data types.*

* **Day 1: Introduction & Interface**
  * Download and install Tableau Public (free).
  * Explore the start page and user interface (Data Source page, Worksheet, Dashboard, Story).
  * *Project:* Load a simple Excel file (like Superstore Sales) and explore the data grid.
* **Day 2: Dimensions vs. Measures & Discrete vs. Continuous**
  * Learn the crucial concepts of Blue (Discrete) vs. Green (Continuous) fields.
  * Understand Dimensions (qualitative, e.g., category, region) vs. Measures (quantitative, e.g., sales, profit).
* **Day 3: Connecting to Different Data Sources**
  * Connect to CSV, Excel, and Google Sheets.
  * Learn how to refresh data sources.
* **Day 4: Data Joins and Relationships**
  * Understand the difference between Joins, Unions, and Relationships.
  * Practice combining two tables in the Data Source tab.
* **Day 5: Data Cleaning Basics**
  * Use Data Interpreter, rename fields, change data types, and create basic folders to organize your data.

---

### **Phase 2: Core Visualizations (Days 6–12)**
*Goal: Master the "Show Me" panel and build the most common types of charts used in business.*

* **Day 6: Bar Charts & Line Charts**
  * Build horizontal and vertical bar charts.
  * Create time-series line charts using dates.
* **Day 7: Geographic Maps**
  * Plot state, country, and postal code data on a map.
  * Customize map layers, background styles, and point sizes.
* **Day 8: Scatter Plots & Packed Bubbles**
  * Build scatter plots to show correlations.
  * Use Packed Bubbles and Treemaps for hierarchical data.
* **Day 9: Sorting, Grouping, and Hierarchies**
  * Learn manual and computed sorting.
  * Create custom groups and geographic or categorical hierarchies (e.g., Year > Quarter > Month).
* **Day 10: Filters and Marks Card**
  * Master the Marks Card (Color, Size, Label, Detail, Tooltip).
  * Apply filters to views, data sources, and contexts.
* **Day 11: Highlighting and Formatting**
  * Use Highlighting actions within a sheet.
  * Format fonts, borders, shading, and axis titles for a clean look.
* **Day 12: Mini-Project 1**
  * *Project:* Build 4 distinct, well-formatted charts using the Superstore dataset (Sales by Region, Profit over Time, Map of Sales by State, Sub-category breakdown).

---

### **Phase 3: Calculations & Analytics (Days 13–19)**
*Goal: Go beyond drag-and-drop by writing custom formulas and using advanced analytical features.*

* **Day 13: Basic Calculations (Calculated Fields)**
  * Learn basic string, number, and date calculations (e.g., Profit Ratio = `[Profit]/[Sales]`).
* **Day 14: Logical Functions**
  * Use `IF-THEN`, `IIF`, and `CASE` statements to categorize data (e.g., defining "High" vs. "Low" sales).
* **Day 15: Aggregate Calculations**
  * Understand row-level vs. aggregate calculations.
  * Use functions like `SUM()`, `AVG()`, and `COUNTD()` (Count Distinct).
* **Day 16: Table Calculations**
  * Apply quick table calculations (Running Total, Percent of Total, Difference from Previous).
  * Understand "Compute Using" (Table Across vs. Table Down).
* **Day 17: Parameters**
  * Create parameters to make visualizations dynamic (e.g., let the user select top N products or switch between metrics like Sales and Profit).
* **Day 18: Reference Lines, Trend Lines, and Distributions**
  * Add reference lines, average lines, and forecasting to charts.
* **Day 19: Mini-Project 2**
  * *Project:* Create a calculated field for profit margins, build a parameter-driven "Top N Products" chart, and add a running total trend line.

---

### **Phase 4: Dashboards & Storytelling (Days 20–25)**
*Goal: Combine individual sheets into cohesive, interactive dashboards and tell a story with data.*

* **Day 20: Dashboard Layouts and Containers**
  * Understand Tiled vs. Floating layouts.
  * Use Horizontal and Vertical containers to structure a dashboard cleanly.
* **Day 21: Dashboard Actions (Filtering & Highlighting)**
  * Set up interactive filters where clicking one chart filters another chart on the dashboard.
  * Use URL actions and Highlight actions.
* **Day 22: Dashboard Design Best Practices**
  * Learn color theory for data visualization (avoiding rainbow palettes, using color purposefully).
  * Design for different device layouts (Desktop, Tablet, Phone).
* **Day 23: Tooltips and Formatting**
  * Customize tooltips with "Viz in Tooltip" (putting a chart inside a hover-over tooltip).
* **Day 24: Stories in Tableau**
  * Learn how to use the "Story" tab to present a sequence of insights to stakeholders.
* **Day 25: Mini-Project 3**
  * *Project:* Build an interactive Executive Dashboard combining 3-4 sheets with cross-filtering and a clean layout.

---

### **Phase 5: Publishing, Portfolio, & Next Steps (Days 26–30)**
*Goal: Share your work with the world, prepare for certification, and establish a portfolio.*

* **Day 26: Tableau Public & Sharing**
  * Create a Tableau Public profile.
  * Publish your workbooks to the cloud and adjust sharing settings.
* **Day 27: Performance Optimization**
  * Learn tips to make dashboards load faster (extracts vs. live connections, reducing marks, hiding unused fields).
* **Day 28: Capstone Project (Part 1 - Data & Analysis)**
  * Choose a dataset of interest (from Kaggle, Makeover Monday, or UN data).
  * Clean the data, perform exploratory analysis, and draft the core questions you want to answer.
* **Day 29: Capstone Project (Part 2 - Dashboard & Publication)**
  * Build a polished, interactive dashboard based on your capstone data.
  * Publish it to your Tableau Public profile.
* **Day 30: Review & Next Steps**
  * Review community resources (Tableau Community Forums, Workout Wednesday, Makeover Monday).
  * *Optional:* Look into the **Tableau Desktop Specialist Certification** exam if you want formal credentials.

---

### **Recommended Free Resources for the Student:**
1. **Tableau Public Free Training Videos:** (Official Tableau website has phenomenal structured videos).
2. **Makeover Monday:** A weekly social data project great for practicing real-world chart building.
3. **Workout Wednesday:** Weekly challenges to test advanced Tableau calculation and design skills.
4. **Andy Kriebel's YouTube Channel:** One of the best educators for Tableau tips and tricks.

## P14 V1: DevOps Engineer (Fresher (0-1 yr))
Learn: ['Jenkins']
Problems: ['contains a web link', 'contains a salary or promise word']

Here is a structured **30-Day Jenkins Learning Plan** designed for a student. It assumes a daily commitment of **1 to 1.5 hours**.

---

### **Prerequisites Checklist**
Before starting, ensure you have basic knowledge of:
* Linux terminal commands (basic navigation, file editing).
* Git & GitHub (commit, push, pull, repository management).
* Basic Docker knowledge (containers, images).

---

## 🗓️ Week 1: Introduction, Architecture & Basic Jobs

**Goal:** Understand CI/CD concepts, set up Jenkins, and create simple automated jobs.

* **Day 1: What is CI/CD?**
  * Learn the concepts of Continuous Integration (CI) and Continuous Deployment (CD).
  * Understand Jenkins' role in the DevOps ecosystem.
* **Day 2: Installing Jenkins**
  * Install Jenkins locally using **Docker** (recommended) or on a local Linux VM.
  * Complete the initial setup wizard, unlock Jenkins, and install recommended plugins.
* **Day 3: Jenkins Architecture**
  * Learn Jenkins core concepts: Controller (Master) vs. Agents (Nodes), Workspace, Plugins, and Jobs.
  * Explore the Jenkins UI dashboard.
* **Day 4: Creating Your First Freestyle Job**
  * Create a simple "Freestyle Project".
  * Run basic shell commands (`echo`, `date`, `ls`) in the build step.
  * View build history and console logs.
* **Day 5: Source Code Management (SCM) Integration**
  * Connect a GitHub repository to a Freestyle job.
  * Configure Jenkins to pull code from Git and run a basic build script.
* **Day 6: Build Triggers & Post-Build Actions**
  * Learn how to trigger builds manually, periodically (Cron expression), or via Git polling.
  * Add post-build actions (e.g., archived artifacts, mock email notifications).
* **Day 7: Week 1 Review & Practice**
  * **Task:** Create a Freestyle job that pulls a simple HTML/JS project from GitHub and archives the build outputs.

---

## 🗓️ Week 2: Pipeline as Code (Jenkinsfile)

**Goal:** Master Jenkins Pipelines—the industry standard way of writing build logic.

* **Day 8: Freestyle vs. Pipeline Jobs**
  * Understand why Pipelines are preferred over Freestyle jobs.
  * Learn the difference between **Declarative** and **Scripted** Pipeline syntax (Focus on Declarative).
* **Day 9: Declarative Pipeline Basics**
  * Learn key blocks: `pipeline`, `agent`, `stages`, `stage`, and `steps`.
  * Write your first pipeline inside the Jenkins UI editor.
* **Day 10: The `Jenkinsfile`**
  * Create a file named `Jenkinsfile` inside your Git repository.
  * Configure Jenkins to pull the `Jenkinsfile` directly from GitHub (Pipeline from SCM).
* **Day 11: Environment Variables & Parameters**
  * Learn built-in Jenkins environment variables (`BUILD_NUMBER`, `JOB_NAME`).
  * Define custom environment variables and parameterized builds (user inputs).
* **Day 12: Pipeline Controls & Post Conditions**
  * Learn `post` execution blocks (`always`, `success`, `failure`, `changed`).
  * Use `when` conditions to control stage execution.
* **Day 13: Error Handling & Timeout**
  * Implement timeouts, retries, and manual approval stages (`input` step).
  * Learn basic Groovy syntax for error handling (`try-catch`).
* **Day 14: Week 2 Mini-Project**
  * **Task:** Write a multi-stage `Jenkinsfile` (Lint $\rightarrow$ Test $\rightarrow$ Build $\rightarrow$ Deploy Simulation) with failure notification steps.

---

## 🗓️ Week 3: Integrations, Docker & Distributed Builds

**Goal:** Expand Jenkins functionality using plugins, Docker containers, and build nodes.

* **Day 15: Plugin Management**
  * Learn how to search, install, update, and manage plugins.
  * Explore top plugins (Git, Docker, Slack/Discord, Pipeline, Credentials).
* **Day 16: Security & Credentials Management**
  * Store sensitive data safely using Jenkins Credentials Manager (SSH keys, tokens, passwords).
  * Access credentials safely inside a `Jenkinsfile` using `withCredentials`.
* **Day 17: Docker Integration - Part 1**
  * Install the Docker plugin in Jenkins.
  * Run build steps inside a Docker container using a `Jenkinsfile` (e.g., `agent { docker { image 'node:18' } }`).
* **Day 18: Docker Integration - Part 2**
  * Build a Docker image inside a Jenkins pipeline using a local `Dockerfile`.
  * Push the built image to Docker Hub securely.
* **Day 19: Distributed Builds (Nodes & Agents)**
  * Understand why distributed builds are needed (offloading the Controller).
  * Set up a second local machine/VM or Docker container as a permanent Jenkins Agent via SSH.
* **Day 20: Dynamic Docker Agents**
  * Configure Jenkins to spin up dynamic Docker containers on demand to act as short-lived build agents.
* **Day 21: GitHub Webhooks**
  * Set up GitHub Webhooks (using ngrok for local setups or a cloud server).
  * Trigger automated Jenkins builds automatically every time code is pushed to GitHub.

---

## 🗓️ Week 4: Security, Best Practices & Capstone Project

**Goal:** Secure your setup, learn production best practices, and build a portfolio project.

* **Day 22: User Management & Authorization**
  * Set up user accounts in Jenkins.
  * Configure Role-Based Access Control (RBAC) using the **Matrix Authorization** or **Role Strategy** plugin.
* **Day 23: Backup, Restore & Maintenance**
  * Understand what files are stored in `JENKINS_HOME`.
  * Practice backing up and restoring Jenkins configuration and job histories.
* **Day 24: Shared Libraries (Introduction)**
  * Learn what Jenkins Shared Libraries are and why large teams use them to reuse pipeline code.
* **Day 25: Troubleshooting & Log Analysis**
  * Learn how to diagnose pipeline failures, agent connection drops, and system resource issues via Jenkins logs.
* **Day 26–28: Capstone Project (End-to-End CI/CD Pipeline)**
  * **Project Requirements:**
    1. Create a simple Web Application (Node.js, Python Flask, or Java).
    2. Write unit tests for the app.
    3. Create a `Jenkinsfile` that automatically runs on GitHub push (via Webhooks).
    4. Pipeline steps:
       * **Stage 1:** Lint code.
       * **Stage 2:** Run Unit Tests.
       * **Stage 3:** Build Docker Image.
       * **Stage 4:** Push Docker Image to Docker Hub.
       * **Stage 5:** Deploy container locally/to a staging server.
       * **Stage 6:** Send build status notification (Slack/Discord/Email).
* **Day 29: Project Documentation & Portfolio**
  * Clean up your GitHub repository.
  * Add a detailed `README.md` explaining your architecture, pipeline workflow, and steps to reproduce.
* **Day 30: Final Review & Next Steps**
  * Review all key concepts.
  * Explore alternatives & modern tools (GitHub Actions, GitLab CI, ArgoCD) to understand where Jenkins fits today.
